Farzin 0.5.2 OwnNet is a UCI chess engine written in Rust, licensed under
GPL-3.0-only. This maintenance release adds complete license documentation
and release packaging; its search and FZN2-b1 network are unchanged from 0.5.1.

Primary Windows x64 executable:
https://github.com/ar-karkon/farzin/releases/download/v0.5.2/farzin-0.5.2-windows-x64-avx2-bmi2.exe
Release, ZIP with documentation, checksums and corresponding source:
https://github.com/ar-karkon/farzin/releases/tag/v0.5.2

The main executable requires x86-64-v3 (AVX2, BMI1/BMI2 with PEXT, FMA,
LZCNT, MOVBE and POPCNT). AVX2 without BMI2 and x86-64-v2/POPCNT alternatives
are also provided. Windows 10/11 x64; no Rust or Python installation needed.
It supports UCI, configurable Hash and Threads, ponder and Move Overhead.

The edition embeds only Farzin's independently trained FZN2-b1 weights,
SHA-256 3ec5aa7e6c16b1ea6bd366ad873f4b649da310c91204915000bfd5f1e90ebfc0.
Training used Farzin's own self-play/search positions and Rust trainer,
warm-starting from Farzin's earlier FZN2-a1. For full disclosure, training
labels were static evaluations generated using the CC0 Stockfish-project
network nn-ad9b42354671.nnue through Farzin's independent inference code.
This is teacher distillation. No pretrained Stockfish weights are embedded
in the competition executable. Detailed provenance accompanies the release.
